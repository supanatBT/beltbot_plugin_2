## ยืนยันแล้ว

1. **tool รับพารามิเตอร์ไม่ได้** — r2 เรียก `search_catalogue` 8 ครั้งใน 3 เทิร์น · args = `{}` ทุกครั้ง ·
   ได้ "ต้องระบุเงื่อนไขอย่างน้อยหนึ่งข้อ" ทุกครั้ง · LLM ลองซ้ำ 2–3 รอบ → เทิร์นนั้นใช้ 10.7–17.5 s (ปกติ ~4 s)
   ต้นเหตุ `core/tools.py::ToolLog.track` ห่อเป็น `(*args, **kwargs)` · ใช้ห่อ tool ของ Movex ด้วย
2. **C1 ตอบข้อเท็จจริงผิด** — "พื้นที่เปิดไม่ต่ำกว่า 50%" → `parse` เจอ "ต่ำกว่า" ใน "ไม่ต่ำกว่า" → ค้น ≤ 50 (66/68) ·
   บอทตอบ "พื้นที่เปิดสูงสุดในแคตตาล็อก 50.0%" · จริง EC508 R / EC508 TR = 58%
3. **เลขตอบแบรนด์รั่วเข้าค่าค้น** — ตอบ "2" (Modutech) → `parse` อ่านเป็น strength ≥ 2 → ค้นได้ 68/68 ·
   r2 คำตอบยังถูก (B1 · B4) เพราะ LLM คัดเองจากรายการเต็ม — ถูกเพราะ LLM ไม่ใช่เพราะโค้ด
4. **คำถามระดับทั้งแคตตาล็อกไม่มีทางตอบ** — "กี่รุ่น" · "เบาที่สุด" → ถามงาน → ถามพิทช์ วนต่อ แม้ลูกค้าบอกว่าไม่มีงานเฉพาะ
5. **ทางค้นตามการใช้งานคืน 5 รุ่นจากเวกเตอร์** — E1 (แห้ง ≥ 90 °C) ตอบ 5 รุ่น จาก 60 รุ่นที่มีเกรดทนแห้ง ≥ 90 °C ·
   B5 (ระบายน้ำ) สูงสุดที่เสนอ 38% ไม่มี EC508 R/TR 58% · ทั้งสองข้อเขียนว่า "เบื้องต้น" ไม่ได้อ้างว่าครบ
